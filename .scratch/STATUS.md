# Skills

Fase: running
Resumo: Skills compartilhadas para escrita, planejamento, revisão, publicação e diagramas nos projetos.
Atualizado: 2026-10-10

## Sobre
Mantém instruções e recursos reutilizáveis para os harnesses usados pelo operador. As skills cobrem escrita em português, higiene de publicação, especificações, tickets, revisão de PRs, diagramas e consulta a grafos.

O instalador cria symlinks a partir de `skills/` para as pastas dos harnesses. A instalação de `setup` em `~/.agents/skills` aponta para este checkout, conforme conferido nesta atualização. O [README](../README.md) lista as skills e os comandos de instalação.

## Funcionalidades
- Escrita em PT-BR e revisão de texto [live]
- Verificação de autoria e conteúdo antes de publicação [live]
- Planejamento com specs, tickets e Project Hub [live]
- Entrega com implementação, revisão e correção por subagents [live]
- Diagramas de arquitetura e consulta a grafos [live]
- Leitura compartilhada de tickets para o Project Hub e o Mirante [live]
